GitHub me data save karo

Repo aur path GitHub Pages ke URL se apne aap bhar jate hain; branch khali chhodo to default branch use hogi. Har device par sirf ek baar token daalo, ya "setup link" dusre device par kholo. Uske baad projects sab devices me apne aap sync hote hain. Token na ho to data sirf padh sakte ho. Token sirf us device ke browser me rehta hai.
Is device ko setup karo:Ek baar passphrase daalo, GitHub token apne aap set ho jayega.
